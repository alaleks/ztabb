# Создание аналога GUI терминала https://tabby.sh/ только на языке Zig

## Требования
 - минимум аллокацмй
 - простоый код
 - тестирование
 - поддержка Zig 0.16.0+
 - нативность (желательно все делать в рамках Zig)

 ## Возможности
 - Возможность открывать новые вкладки
 - Поддержка ssh в том числе ssh key, если на компьютере пользователя есть ~/.ssh/config отображение имен подключение и если выбор подключения - установка ssh подключения в данной вкладке
 - Две темы - темная и светлая, темная по умолчанию
 - Кроссплатформенность (поддержка MacOS, Linux, Windows)
