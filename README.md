# ztabb
ztabb современный терминальный клиент на Zig: минимум потребление памяти, скорость и удобство.

 ## Roadmap
 - [ ] Поддержка ZSH и шрифтов
 - [ ] Темизация - светлая и темная темы
 - [ ] Поддержка SSH соединений: если на компьютере пользователя есть ~/.ssh/config отображение имен подключение, поддержка SSH ключей и установка ssh подключения в данной вкладке
 - [ ] Подсветка синтаксиса комманд
